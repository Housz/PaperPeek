# Provider marks in the model header

Bundled monochrome marks identify the configured API provider, not PaperPeek endorsement or affiliation. Model names remain the actual configured IDs; no network image request is made. Unknown providers should use the neutral AI fallback, not an unrelated provider logo.

Sources (npm registry packages, unmodified SVGs):
- OpenAI: `simple-icons@13.21.0/icons/openai.svg`
- DeepSeek: `simple-icons@16.37.0/icons/deepseek.svg`
- Gemini: `simple-icons@16.37.0/icons/googlegemini.svg`

Simple Icons artwork is distributed under CC0 1.0 (`public/provider-icons/LICENSE.txt`). CC0 does not grant trademark rights; these marks are used solely for nominative provider identification. Review provider brand requirements before a public release. No release is made by this development change.
