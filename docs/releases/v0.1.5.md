# PaperPeek v0.1.5 · Markdown rendering and browser icon

This is the **experimental Chrome extension release** addressing [Issue #7](https://github.com/Housz/PaperPeek/issues/7) and [Issue #11](https://github.com/Housz/PaperPeek/issues/11).

## Fixed

- **Markdown actually renders:** assistant replies now display headings, **bold**, lists, tables, quotations, inline code and fenced code instead of showing raw `##`, `**` and Markdown syntax. PDF page hints remain clickable where the referenced page exists.
- **Paper Card preview:** the Card tab defaults to a formatted Markdown preview. Use **查看源码** to inspect the exact Markdown text; Copy and **保存 .md** continue to export the unchanged source, suitable for Obsidian and other knowledge bases.
- **Safe untrusted formatting:** the bundled local Markdown renderer escapes raw HTML; image loading and unsafe URL schemes are disabled. The Markdown parser is pinned to the patched `markdown-it@15.0.3`. No remote renderer or external scripts.
- **Original PaperPeek browser icon:** the four approved transparent PNG assets from the issue's existing [asset commit](https://github.com/Housz/PaperPeek/commit/6f1d76681cb0d5265bbf198598f0071251a300b8) are now packaged in Chrome Manifest V3. Sizes: **16, 32, 48 and 128 px**, with matching toolbar icons.

## Download and install

1. Under **Assets**, download `PaperPeek-v0.1.5-chrome.zip`, **not** GitHub's auto-generated source ZIP.
2. Unzip to a stable local folder. Open Chrome `chrome://extensions`, enable **Developer mode**, select **Load unpacked**, and choose the extracted directory directly containing `manifest.json`.
3. If updating an existing unpacked install, replace the files **in the same directory** and reload the extension. Export important Markdown first; temporary tab sessions may be cleared by extension reload.
4. The release also includes `SHA256SUMS.txt` to verify the archive.

## Scope and verification

GitHub Actions rebuilds the extension from the merged commit after TypeScript checks, unit and mocked Side Panel journey tests, and verifies that all four PNG files are included in the final ZIP.

**Remaining limitations:** actual desktop Chrome and live-provider behavior remain a separate manual acceptance step; restricted/one-time PDF URLs, image-only PDFs and PDF precision highlights are still outside this version. Model-generated answers and references need researcher verification. No server is operated by PaperPeek and model API keys are never bundled in releases.
