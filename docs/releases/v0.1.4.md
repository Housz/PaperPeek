# PaperPeek v0.1.4 · Chrome Extension (Experimental)

This is the **GitHub Release build** of the current v0.1.4 source. The version stays **0.1.4**, including the current-model status display added during release preparation.

## Highlights

- **Tab-scoped reading workspaces:** return to an open PDF tab without losing its already completed overview, chat, unfinished question or Markdown Paper Card.
- **Model status:** the single top toolbar shows the currently configured AI provider and the exact model ID used for new requests. On narrow side panels, hover to see the full value.
- **Clear settings action:** a conventional gear icon, not a sun/brightness symbol.
- **Public and local PDF workflows:** arXiv and other accessible HTTPS PDFs, manual PDF selection, optional re-detection, local file access with Chrome permission.
- **Bring your own API Key:** OpenAI and DeepSeek model discovery, model test and optional local persistence. Gemini remains a manual model ID option.
- **Concise Markdown Card:** copy/download a summary with the research question, methods, evidence and limitations.

## Install the unpacked extension

1. In **Assets** below, download **`PaperPeek-v0.1.4-chrome.zip`** (not GitHub's auto-generated source-code ZIP).
2. Unzip to a stable local directory.
3. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the unzipped directory that directly contains `manifest.json`.
4. Pin PaperPeek and open its Side Panel. Configure a user-owned API Key in Settings.
5. For PDFs opened through `file://`, enable **Allow access to file URLs** in the extension details if desired.

To update an existing unpacked installation without losing its extension identity/settings, overwrite the **same** local extension folder and click **Reload** in `chrome://extensions`. Avoid uninstalling first. Completed temporary paper sessions may be cleared on extension reload/update; export important Markdown beforehand.

## Checks and integrity

Built by GitHub Actions from the published commit after strict TypeScript checks, unit and mocked-UI journey tests, and a production Vite build. Download `SHA256SUMS.txt` to verify the ZIP's SHA-256.

**Experimental limitations:** Real desktop Chrome publisher compatibility and end-to-end BYOK calls have not been exhaustively validated; PDFs requiring login/POST/`blob:` may need manual import. Chrome `storage.session` is ephemeral: browser restart, extension reload or tab closure can clear saved paper work.
